- Push 到 `main`、`develop`、`feature/**`、`fix/**` 时运行。
- 面向 `main` 或 `develop` 的 Pull Request 时运行。
- 后端使用 Java 17、MySQL 8 和 Fake LLM，执行 41 项测试并打包。
- 前端使用 Node 20，执行确定性安装、依赖审计、4 项单测、类型检查和生产构建。
- Gitleaks 扫描完整提交历史。
- PR 使用 Trivy 扫描 Maven/npm 依赖，发现 HIGH/CRITICAL 漏洞时失败。
- 同一分支的新运行会取消旧运行，减少无效 CI 消耗。
