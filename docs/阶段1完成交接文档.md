# 电影推荐系统阶段 1 完成交接文档

> 项目路径：`D:/个人项目/movie_recommendation_systems`  
> 完成日期：2026-09-19  
> 功能分支：`feature/rest-api-foundation`

## 1. 完成范围

- 新增明确的注册、登录、资料更新、评分、评论和收藏请求 DTO，并使用 Bean Validation 校验。
- 新增脱敏响应 DTO，写接口不再直接返回包含用户 ID 的数据库实体字段。
- 统一响应为 `code`、`message`、`data`、`requestId`、`timestamp`。
- 新增请求 ID 过滤器，响应头使用 `X-Request-ID`，请求可携带合法 ID 便于链路追踪。
- 新增全局异常处理，参数、认证、权限、不存在、冲突和系统异常分别返回真实 HTTP 状态。
- 核心业务接口迁移到 `/api/v1`；静态海报路径继续使用 `/api/posters`。
- 新增 SpringDoc OpenAPI，Swagger UI 路径为 `/swagger-ui.html`。
- 新增显式 CORS 白名单；生产环境必须提供具体 Origin，拒绝 `*`。
- 新增 `dev`、`test`、`prod` 环境配置，并将 JWT 默认有效期统一为 15 分钟。
- 前端 API 已同步到 v1，并处理 401、403、404、409、429、503 和请求 ID。

## 2. 主要接口

```text
POST   /api/v1/auth/register
POST   /api/v1/auth/login
GET    /api/v1/users/me
PATCH  /api/v1/users/me
GET    /api/v1/users/me/ratings
GET    /api/v1/users/me/favorites
POST   /api/v1/ratings
PUT    /api/v1/ratings/{id}
DELETE /api/v1/ratings/{id}
POST   /api/v1/comments
GET    /api/v1/comments
POST   /api/v1/comments/{id}/like
POST   /api/v1/favorites
DELETE /api/v1/favorites/{movieId}
GET    /api/v1/movies
GET    /api/v1/movies/search
GET    /api/v1/movies/{id}
```

旧业务 JSON 路径已删除，前端已经同步迁移。海报 URL 未迁移，以免破坏数据库和本地文件引用。

## 3. 状态码约定

| 场景 | 状态码 |
| --- | --- |
| 查询或更新成功 | 200 |
| 注册、评分、评论、收藏创建成功 | 201 |
| 参数或 JSON 格式错误 | 400 |
| 未登录或登录失败 | 401 |
| 无权操作 | 403 |
| 资源不存在 | 404 |
| 请求方法不支持 | 405 |
| 用户名、评分或收藏冲突 | 409 |
| Content-Type 不支持 | 415 |
| 未处理系统错误 | 500 |
