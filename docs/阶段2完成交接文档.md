# 电影推荐系统阶段 2 完成交接文档

> 项目路径：`D:/个人项目/movie_recommendation_systems`
> 完成日期：2026-09-19
> 主题：用户 CRUD、用户状态与 RBAC

## 1. 完成范围

- 新增 Flyway `V2__add_user_status_and_rbac.sql`，为 `user` 增加 `status`（`ACTIVE`、`DISABLED`、`DELETED`）。
- 新增 `role`、`permission`、`user_role`、`role_permission` 表和 USER/ADMIN 初始角色、权限及旧 `user.role` 兼容迁移。
- JWT 认证从 RBAC 表读取角色和权限；仅 ACTIVE 用户可以建立认证上下文。
- 开启 `@EnableMethodSecurity`，管理员控制器使用类级角色保护和方法级权限保护。
- 新增管理员用户分页、详情、创建、修改、软注销接口。
- 新增本人注销接口；注销/禁用均为状态变更，不物理删除业务记录。
- 管理员不能禁用、注销或降级自己的账户。
- 用户资料响应增加 `status`，注册默认 ACTIVE，禁用/注销账户无法登录。
- 保留评分、收藏、评论现有归属校验，并补充评分越权测试。

## 2. 新增接口

```text
GET    /api/v1/admin/users?page/current&size
GET    /api/v1/admin/users/{id}
POST   /api/v1/admin/users
PATCH  /api/v1/admin/users/{id}
DELETE /api/v1/admin/users/{id}
DELETE /api/v1/users/me
```

管理员用户创建/修改支持 `role`、`status`、`preferences` 和密码字段；密码仍使用 BCrypt，不出现在响应中。

## 3. 权限矩阵

| 操作 | USER | ADMIN |
| --- | --- | --- |
| 查看电影、评分/收藏/评论 | 允许 | 允许 |
| 用户列表/详情 | 拒绝 | `user:read` |
| 创建/修改/注销用户 | 拒绝 | `user:write` |
| 爬取、导入和下载任务 | 拒绝 | `crawl:execute` |

URL 规则和方法级 `@PreAuthorize` 同时生效，前端路由不承担安全边界。

## 5. 数据库迁移说明

不要修改已执行的 V1。部署到已有数据库时运行 Flyway，让 V2 自动添加状态列、RBAC 表和初始化数据。生产环境需先备份数据库，并确认当前数据库账号拥有建表、加列和外键权限。
