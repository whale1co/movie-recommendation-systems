## 8. 注意事项

1. 不要提交数据库备份、海报、CSV、`target`、`dist` 或 `node_modules`。
2. 不要在代码或文档中写入真实数据库密码、JWT Secret 或未来的 LLM API Key。
3. 不要修改已经执行的 Flyway V1；后续结构变更从 V2 开始。
4. 当前前端把 JWT 保存在 `localStorage`，这是已知风险，但应在认证强化阶段统一改造，阶段 1 只需确保现有联调不回归。
5. 当前 `Result.error()` 只改变 JSON 中的 `code`，可能仍返回 HTTP 200；阶段 1 必须修正这一点。
6. 当前多个控制器直接接收 `Map<String, Object>` 或 `Map<String, String>`；阶段 1 要逐步替换为 DTO，避免空值转换和类型错误。
7. 新增公共抽象应保持克制，优先沿用当前 Spring Boot 项目结构，不要在阶段 1 同时引入 RBAC、Refresh Token 或 LLM，避免扩大改动范围。
